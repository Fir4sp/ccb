Sistema CCB — Guia de Instalação

Fase 2 (fundação) · ambiente de teste na Hostinger · outubro de 2026

Este guia leva o sistema para o ar no endereço ccb.konstante.com.br, separado de tudo da Konstante. Tudo é feito pelo hPanel e pelo navegador, sem programas e sem terminal. Leva uns 20 minutos.

SEU CÓDIGO DE INSTALAÇÃO (usado no passo 6)QDPY-GHEH-AWKV
Arquivos que você recebeu: sistema-ccb-para-subir.zip (é o que vai para a Hostinger) e este guia. O arquivo codigo-fonte.zip é só cópia de segurança do código e não precisa ser enviado.

O que tem dentro do zip

sistema-ccb/ ├── ccb_app/ ← o "motor" do sistema e o acesso ao banco. Fica FORA do site. └── site/ ← as telas do sistema. Vira a pasta do subdomínio.

A pasta ccb_app nunca fica visível na internet. Por isso ela vai num lugar diferente da pasta site.

Passo a passo

1

Criar o subdomínio

  1. No hPanel, entre no site konstante.com.br → menu Domínios → Subdomínios.
  2. Em "Criar novo subdomínio", digite ccb e clique em Criar.
  3. Na lista, anote a pasta que aparece ao lado de ccb.konstante.com.br. Normalmente é public_html/ccb.
2

Conferir o cadeado (HTTPS) e a versão do PHP

  1. Menu Segurança → SSL: o subdomínio ccb.konstante.com.br precisa aparecer como Ativo. Se não aparecer, clique em instalar SSL para ele. Pode levar alguns minutos.
  2. Menu Avançado → Configuração do PHP: escolha PHP 8.3 (8.2 também serve) e salve.
3

Criar o banco de dados

  1. Menu Bancos de dados → Bancos de dados MySQL.
  2. Preencha nome do banco (ex.: ccb), usuário (ex.: ccb) e uma senha forte. Clique em Criar.
  3. A Hostinger coloca um prefixo nos nomes, como u123456789_ccb. Anote o nome completo do banco, o usuário completo e a senha.
Use um banco novo. Não use o banco do sistema da Konstante.
4

Enviar e descompactar o zip

  1. Menu Arquivos → Gerenciador de Arquivos.
  2. Suba um nível acima de public_html, até a pasta que contém o public_html (costuma ser domains/konstante.com.br ou a pasta inicial da conta).
  3. Envie o arquivo sistema-ccb-para-subir.zip para essa pasta (botão de upload).
  4. Clique com o botão direito no zip → Extrair. Vai aparecer a pasta sistema-ccb.
5

Colocar cada pasta no lugar

  1. Abra sistema-ccb. Mova a pasta ccb_app para a pasta de cima, ficando ao lado do public_html.
  2. Entre em public_html e apague a pasta ccb que o hPanel criou no passo 1 (ela está vazia).
  3. Volte em sistema-ccb, mova a pasta site para dentro do public_html e renomeie site para ccb.
  4. Pode apagar a pasta sistema-ccb (vazia) e o zip.

No fim, deve ficar assim:

domains/konstante.com.br/ (ou a pasta inicial da conta) ├── ccb_app/ ← motor do sistema, fora da internet └── public_html/ ├── (arquivos do site da Konstante — não mexa) └── ccb/ ← telas do Sistema CCB (era a pasta "site") ├── index.html ├── instalar.php └── api/ …
Se o hPanel tiver mostrado outra pasta no passo 1, use essa pasta no lugar de public_html/ccb. O sistema encontra o ccb_app sozinho, desde que ele esteja até 3 pastas acima.
6

Rodar o instalador

  1. No navegador, abra https://ccb.konstante.com.br/instalar.php
  2. Preencha:
    • Código: QDPY-GHEH-AWKV
    • Banco: nome, usuário e senha anotados no passo 3. Servidor: deixe localhost.
    • Organização: pode deixar como está.
    • Administrador: seu nome, seu e-mail e uma senha (8 ou mais caracteres, com letras e números).
    • Dados de demonstração: deixe marcado para mostrar o sistema à coordenação.
  3. Clique em Instalar. Deve aparecer "Instalação concluída."

O instalador cria as tabelas, a organização, os 4 grupos e o seu usuário. Depois disso ele se desliga sozinho e o código para de valer.

7

Apagar o instalador e entrar

  1. No Gerenciador de Arquivos, apague o arquivo public_html/ccb/instalar.php.
  2. Abra https://ccb.konstante.com.br e entre com o e-mail e a senha do passo 6.
  3. No primeiro acesso, o sistema pede uma senha nova. É normal.
8

Instalar no celular

  • Android (Chrome): abra o endereço → menu ⋮ → Instalar app.
  • iPhone (Safari): abra o endereço → botão Compartilhar → Adicionar à Tela de Início.

No computador, é só usar pelo navegador, no mesmo endereço.

Se algo der errado

O que apareceO que fazer
"Pasta ccb_app não encontrada"A pasta ccb_app ficou no lugar errado. Refaça o passo 5: ela fica ao lado do public_html, não dentro.
"Não foi possível conectar ao banco"Confira no hPanel o nome completo do banco e do usuário (com o prefixo u123…_) e a senha. Se esqueceu a senha, troque-a no hPanel e tente de novo.
"Sem permissão para gravar o arquivo de configuração"No Gerenciador de Arquivos, clique com o botão direito em ccb_app/config → Permissões → 755.
Página branca ou "Erro 500"Confira a versão do PHP (passo 2): precisa ser 8.2 ou 8.3.
O navegador avisa "site não seguro"O SSL do subdomínio ainda não ficou pronto (passo 2). Espere alguns minutos.
"Este banco já tem uma organização cadastrada"O sistema já foi instalado nesse banco. Abra o endereço normal e entre com seu usuário.

Se travar em qualquer passo, me mande uma foto da tela que eu te digo o que fazer.

O que o sistema já faz (Fase 2)

  • Entrada segura: login por e-mail e senha. A senha provisória é trocada no primeiro acesso. Depois de 5 senhas erradas, o acesso bloqueia por 15 minutos.
  • Cada um vê só o que é seu: a Casa vê só a própria casa, a Coordenação só o seu grupo, a Orientadora só as casas atribuídas, a Gestão todas.
  • Administração: cadastro de usuários (perfis, casa e função), Casas de Oração (cada uma já com seu DML Local), grupos, alçadas e auditoria.
  • Web e celular: mesmo endereço e mesmo login. No celular, menu embaixo e app instalável; no computador, menu lateral.
  • Testado: 52 testes automáticos aprovados, mais a instalação feita do zero numa estrutura igual à da Hostinger.
